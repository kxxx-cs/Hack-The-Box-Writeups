1. What type of architecture allows nodes to act as both client and server?\
Ans: Peer-to-peer

2. What architecture combines elements of both Client-Server and Peer-to-Peer models?\
Ans: hybrid

3. Which cloud service model involves accessing applications over the internet without managing the underlying infrastructure?\
Ans: SaaS

4. In which architecture is the control plane separated from the data plane? (Format: two words, one of which is hyphenated)\
Ans: software-defined networking

5. Which architecture is known for decentralized data sharing without a central server?\
Ans: Peer-to-peer

6. What model is used by video conferencing apps to combine centralized coordination with peer-to-peer data transfer?\
Ans: hybrid
