1. What IPv4 address is used when a host wants to send and receive network traffic to itself?\
Ans: 127.0.0.1

2. What is the the name of the Program listening on localhost:5901 of the Pwnbox?\

3. Which network interface allows us to interact with target machines in the HTB lab environment?\
Ans: tun0

4. What command-line tool is used to configure network interfaces and display their current status?\
Ans: ifconfig

5. What command-line tool is used to display network connections, routing information, and interface statistics?\
Ans: netstat
