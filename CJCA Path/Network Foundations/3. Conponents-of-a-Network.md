1. What type of network cable is used to transmit data over long distances with minimal signal loss?\
Ans: fiber-optic

2. Which protocol manages data routing and delivery across networks?\
Ans: TCP/IP

3. What software is used to oversee and administer network operations? (Format: 3 words)\
Ans: network management software

4. What software is used to protect individual devices from unauthorized network access? (Format: 1 word)\
Ans: Firewall

5. What type of cable is used to connect components within a local area network for high-speed data transfer?\
Ans: Ethernet

6. Which device connects multiple networks and manages data traffic to optimize performance?\
Ans: Router
